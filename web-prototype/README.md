# web-prototype

A simple static website built as a practice project for a Git and GitHub course. It's a small landing page that links out to two course pages, each embedding a YouTube tutorial video.

## Pages

- **index.html** — Home page ("Cursos Gratis") linking to the two course pages below.
- **curso-html.html** — Short intro to HTML5/CSS3 with an embedded video tutorial.
- **curso-js.html** — Short intro to JavaScript with an embedded video tutorial.

## Structure

```
web-prototype/

```

## Tech Stack

- HTML5
- CSS3

## Running Locally

No build step required — just open `index.html` in a browser, or serve the folder with any static file server.
