🏋️‍♂️ Treine.me

Landing page simples e moderna para um serviço de treinos personalizados, focado em performance, saúde e qualidade de vida.

📌 Sobre o Projeto

O Treine.me é uma página estática desenvolvida com HTML e CSS puro, com o objetivo de apresentar um serviço de treinos exclusivos para usuários.

A interface é limpa, responsiva (base inicial) e utiliza boas práticas de estruturação e estilização.

🚀 Tecnologias Utilizadas
HTML5
CSS3
Google Fonts
Mulish
Open Sans
🎨 Layout

O layout segue um estilo minimalista e moderno, com:

Navegação simples no topo
Seção principal com call-to-action
Botão de ação (WhatsApp)
Imagem ilustrativa
Rodapé com contato
