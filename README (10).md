## English

A collection of front-end projects built for practice with HTML, CSS and JavaScript — landing pages, informational pages, and responsiveness exercises.

### Projects

| Project | Description | Tech Stack | Demo |
|---|---|---|---|
| [Beta](./Beta) | Introductory responsiveness exercise — hero section with a service list | HTML5, CSS3 | — |
| [Furniture-landing-page](./Furniture-landing-page) | Landing page for a custom furniture business, with a minimalist layout | HTML5, CSS3, Google Fonts | — |
| [Galaxies](./Galaxies/Galaxies) | Informational page about the largest galaxies in the universe, with a dark theme and responsive grid | HTML5, CSS3, Google Fonts | [galaxies-neon.vercel.app](https://galaxies-neon.vercel.app) |
| [Training-landing-page](./Training-landing-page) | Landing page (Treine.me) for a personal training service | HTML5, CSS3, Google Fonts | — |
| [fotoblog](./fotoblog) | Image gallery with integration to an image API | HTML5, CSS3, JavaScript | [fotoblog-lac.vercel.app](https://fotoblog-lac.vercel.app) |
| [web-prototype](./web-prototype) | Landing page with course pages (HTML/CSS and JavaScript), a Git/GitHub practice project | HTML5, CSS3 | — |

Each project has its own README with more details.

### Repository structure

```
Websites/
├── Beta/
├── Furniture-landing-page/
├── Galaxies/Galaxies/
├── Training-landing-page/
├── fotoblog/
├── web-prototype/
└── LICENSE
```

### Running locally

All projects are static (no build step required). Clone the repository and open the desired project's `index.html` in your browser, or serve the folder with an extension like Live Server.

```bash
git clone https://github.com/paulopottermarchi/Websites.git
```
