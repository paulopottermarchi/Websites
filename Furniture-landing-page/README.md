## 🎯 About

Simple landing page showcasing custom furniture services with a minimalist design approach. Built as a front-end practice project.

## 🚀 Tech Stack

- HTML5
- CSS3
- Google Fonts (Inter & Open Sans)

## ✨ Features

- Centered layout design
- Custom typography
- Decorative SVG elements
- Social media links
- Orange accent color scheme (`#FF9900`)

## 🖥️ How to Run

Clone and open `index.html` in your browser:
```bash
git clone https://github.com/your-username/custom-furniture-landing-page.git
cd custom-furniture-landing-page
```
